Praktik Debugging: Pemesanan Tiket Bioskop

Masukkan data pemesanan, lalu bandingkan Mode BUG dan Mode FIX.

1. Coba Program

Mode aktif: BUG

Daftar Pemesanan (0)

  • Belum ada pemesanan.

2. Perhatikan Kode JavaScript

✕ Sebelum / BUG 
function prosesBUG(
  customer,
  movie,
  quantityText
) {
  bookings.push({
    customer: customer || "(nama kosong)",
    movie: movie || "(film belum dipilih)",
    quantity: quantityText || "tidak diisi"
  });

  renderBookings();

  showMessage(
    "BUG: pemesanan ditambahkan meskipun data belum lengkap.",
    "success"
  );

  form.reset();
}

Kesalahan: data langsung ditambahkan ke daftar pemesanan tanpa pemeriksaan kelengkapan dan kebenaran input.

✓ Sesudah / FIX 
function prosesFIX(
  customer,
  movie,
  quantityText
) {
  const quantity = Number(quantityText);

  if (
    customer === "" ||
    movie === "" ||
    quantityText === ""
  ) {
    showMessage(
      "Nama, film, dan jumlah tiket wajib diisi.",
      "error"
    );
    return;
  }

  if (
    !Number.isInteger(quantity) ||
    quantity < 1 ||
    quantity > 10
  ) {
    showMessage(
      "Jumlah tiket harus bilangan bulat 1-10.",
      "error"
    );
    return;
  }

  bookings.push({
    customer: customer,
    movie: movie,
    quantity: quantity
  });

  renderBookings();
  showMessage(
    "FIX: pemesanan berhasil ditambahkan.",
    "success"
  );

  form.reset();
}

Perbaikan: sistem memeriksa kelengkapan data dan memastikan jumlah tiket berupa bilangan bulat 1-10 sebelum menyimpan pemesanan.

3. Perbedaan Mode BUG dan Mode FIX

Mode BUG: sistem langsung menambahkan pemesanan tanpa memeriksa apakah nama, film, dan jumlah tiket sudah diisi dengan benar.

Mode FIX: nama dan film wajib diisi, sedangkan jumlah tiket harus berupa bilangan bulat antara 1 sampai 10.

Coba kirim formulir kosong atau isi jumlah tiket dengan angka 0 untuk melihat perbedaan perilakunya.
